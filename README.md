# 🏏 IPL Match Winner & Score Predictor

An interactive, responsive web application designed to predict dynamic IPL 1st innings scores and match winning probabilities using historical ball-by-ball patterns and match parameters.

Developed as part of the **InternPe AI/ML Virtual Internship (Task 3)**.

---

## 🚀 Live Demo
🌐 **Live Web Application:** [https://mdinzemam.github.io/ipl-predictor-app/](https://mdinzemam.github.io/ipl-predictor-app/)

---

## ✨ Features
- **Dynamic Score Estimation:** Calculates safe, median, and aggressive projected totals.
- **Win Probability Engine:** Live probability shifts between batting and bowling franchises.
- **Match Scenarios:** Support for custom venue, current overs, wickets in hand, and run rates.
- **Modern UI:** Sleek dark-themed sports dashboard interface built for high responsiveness.

---

## 🛠️ Tech Stack
- **Frontend / UI:** HTML5, Modern CSS3, JavaScript (ES6)
- **Model Prototyping:** Python, Pandas, Scikit-learn (Google Colab)
- **Deployment:** GitHub Pages

---

## 📌 Project Workflow
1. **Data Preprocessing:** Handled ball-by-ball IPL dataset, filtered consistent franchises, and performed feature encoding.
2. **Modeling:** Trained regression models (Random Forest, Decision Tree, Neural Networks) to evaluate predictive performance.
3. **Web Application:** Deployed an interactive UI accessible across all
